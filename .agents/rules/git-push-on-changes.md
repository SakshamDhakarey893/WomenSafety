# Git Auto-Push Rule

Whenever any changes are made to the codebase in response to user requests:
1. Ensure all modified files and mirrors (e.g. `admin/` and `backend/admin/`) are verified and kept in sync.
2. Stage the changes using `git add`.
3. Commit with a concise and descriptive commit message following conventional commits.
4. Push the changes to GitHub (`git push origin <branch>`).
